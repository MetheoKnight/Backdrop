Backdrop setup

Put a video behind your desktop icons.

A wallpaper that's actually a video

Windows only gives you still pictures. Backdrop draws a video player on the layer behind your icons, so everything on your desktop works like normal and the background moves.

Loops what you give it

Drop in an MP4 or WebM file, or paste a YouTube link. It plays muted and repeats until you swap it out. Imported files are copied into Backdrop's library, so moving the original won't break anything.

One wallpaper per monitor

Backdrop draws your displays to scale at the top of the window. Click a screen, click a wallpaper, done. Or send the same one to every monitor at once.

Make it yours

Put a clock, some text, a picture, or a now-playing widget on top and drag it into place. Change brightness, blur, tint and speed until it looks right. Your changes are saved with the wallpaper.

See what's playing

Add a Spotify-style now-playing card to any wallpaper. It picks up whatever is playing through Spotify, Edge, Chrome or Brave and shows the title, artist and progress.

Stays out of the way

It lives in the system tray. Close the window and the wallpaper keeps playing. Turn on start with Windows and it puts everything back after you sign in.

What's new in 0.3.0

The latest update. Older changes from 0.2.0 are listed underneath.

  1. New

    Now playing widget

    In the wallpaper editor, press Add now playing. You get a Spotify-style card you can drag anywhere — bottom-left, top-right, wherever. Choose vertical or horizontal layout and set the size. It shows the track title, artist, app name and a progress bar. Works with Spotify desktop and media playing in Microsoft Edge, Chrome or Brave (anything that reports through Windows media sessions).

What was new in 0.2.0

The first update to Backdrop. Here's everything that got added then.

  1. New

    Edit any wallpaper

    Hover a wallpaper in your library and press Edit. You get a live preview where you can add a clock (12 or 24 hour, with seconds and the date if you want them), your own text, or an image or GIF, then drag each one where you want it. There are sliders for brightness, contrast, saturation, hue, blur, a colour tint, speed, volume and how the video fits the screen. Press Save and every monitor showing it updates straight away.

  2. New

    Get wallpapers button

    It opens motionbgs.com in your browser. Switch on auto-import and any .mp4 or .webm you download lands in your Backdrop library by itself, so you don't have to dig through your Downloads folder. Backdrop doesn't scrape the site. You use the site's own download buttons.

  3. New

    Start with Windows

    Settings has a switch that launches Backdrop when you sign in. It starts hidden in the tray and puts your wallpaper back. A second switch skips Windows' built-in 10 second wait before startup apps run, if you want your wallpaper up sooner.

  4. Fixed

    Wallpaper missing after sign-in

    If Windows' desktop wasn't ready when Backdrop started, it used to give up and leave you with a plain background. Now it keeps trying for about a minute.

  5. New

    Update notifications

    When a newer version is out, a banner shows up in the app and installs it in one click. Nobody has to come back to this page.

  6. Better

    A proper installer

    It installs for your user account only, so there's no admin password prompt, and there's an option for a desktop shortcut on the last page. Opening Backdrop a second time now just brings up the window that's already running instead of starting a duplicate.

Install it

  1. Download the installer

    —, one file. Works on 64-bit Windows 10 and 11.

  2. Run it

    Windows will probably show a blue "Windows protected your PC" screen. That's because I haven't paid for a code-signing certificate. Click More info, then Run anyway.

  3. Pick your wallpaper

    Tick the desktop shortcut box if you want one, open Backdrop, press Import MP4 (or drag a video into the window) and click it. To add the now-playing widget, edit a wallpaper and press Add now playing.

Questions people ask

Do I need administrator rights?

No. Backdrop installs just for your account, so Windows won't ask for an admin password.

Why does Windows say it protected my PC?

SmartScreen warns about installers from publishers it doesn't know yet, and Backdrop isn't signed with a paid certificate. Click More info, then Run anyway. If you'd like proof the file hasn't been changed, compare its checksum with the one above.

Will it slow down my games?

It's a video playing behind your windows, so it does use some GPU. Backdrop doesn't pause for fullscreen games yet. If you notice a dip, right-click the tray icon near your clock and choose Quit and remove wallpapers.

My YouTube wallpaper shows an error

Some uploaders switch off embedding, and YouTube occasionally rejects embeds from desktop apps. Try a different video, or download the file and import it as an MP4 instead.

Does the now-playing widget work with every app?

It uses Windows' system media session, so anything that reports there will show up — Spotify, Edge, Chrome, Brave, and most other media players. Apps that don't publish a media session won't appear.

Does it send my data anywhere?

There's no account and no tracking. Backdrop only goes online to play YouTube wallpapers and to check for updates.

Where are my wallpapers stored? How do I uninstall?

Imported videos are copied to %APPDATA%\app.backdrop.desktop\library. Delete that folder if you want them gone. To remove the app itself, use Settings, then Apps, then Installed apps.
